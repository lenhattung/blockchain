## PHẦN 2: TẠO SMART CONTRACT NFT (SIMPLE NFT)

### Bước 2: Tạo file SimpleNFT.sol

2.  Đặt tên: `SimpleNFT.sol`

### Bước 3: Viết mã nguồn cho NFT
Copy đoạn code dưới đây vào file. Đây là contract giúp tạo ra NFT và lưu trữ thông tin "người tạo" (Creator) để tính tiền bản quyền (Royalty).

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

// Import thư viện ERC721 từ OpenZeppelin
import "@openzeppelin/contracts/token/ERC721/ERC721.sol";
import "@openzeppelin/contracts/utils/Counters.sol";

contract SimpleNFT is ERC721 {
    using Counters for Counters.Counter;
    Counters.Counter private _tokenIdCounter;

    // Lưu trữ địa chỉ người tạo (Creator) của từng Token ID
    mapping(uint => address) public creators;

    constructor() ERC721("MyNFT", "MNFT") {}

    // Hàm Mint (Tạo NFT)
    function mint(address to, string memory tokenURI) public returns (uint) {
        _tokenIdCounter.increment();
        uint tokenId = _tokenIdCounter.current();

        // Đúc NFT cho địa chỉ 'to'
        _safeMint(to, tokenId);
        
        // Lưu địa chỉ người tạo vào mapping
        creators[tokenId] = to;
        
        // (Tùy chọn) Lưu URI (link ảnh) - Ở đây ta dùng hàm cơ bản của ERC721 để set URI
        _setTokenURI(tokenId, tokenURI);

        return tokenId;
    }

    // Hàm helper để set URI (cho đơn giản, dùng internal của ERC721URIStorage nếu import, 
    // nhưng ở đây ta viết đơn giản hóa hoặc map riêng. Để code gọn, ta dùng mapping riêng cho URI)
    mapping(uint => string) private _tokenURIs;

    function _setTokenURI(uint tokenId, string memory _tokenURI) internal {
        require(_ownerOf(tokenId) != address(0), "URI set of nonexistent token");
        _tokenURIs[tokenId] = _tokenURI;
    }

    function tokenURI(uint tokenId) public view override returns (string memory) {
        return _tokenURIs[tokenId];
    }
}
```

## PHẦN 3: TẠO SMART CONTRACT MARKETPLACE

### Bước 4: Tạo file NFTMarketplace.sol

2.  Đặt tên: `NFTMarketplace.sol`

### Bước 5: Viết mã nguồn cho Marketplace
Copy đoạn code dưới đây. Đây là nơi diễn ra việc rao bán (List) và mua hàng (Buy) có tính Royalty.

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

// Import contract NFT vừa tạo
import "./SimpleNFT.sol";

contract NFTMarketplace {
    SimpleNFT public nftContract;

    // Struct lưu thông tin món hàng đang bán
    struct Listing {
        address seller;
        uint price;
        bool active;
    }

    mapping(uint => Listing) public listings;

    // Sự kiện khi có người mua thành công
    event ItemBought(uint indexed tokenId, address seller, address buyer, uint price);

    constructor(address _nftContractAddress) {
        nftContract = SimpleNFT(_nftContractAddress);
    }

    // HÀM 1: Đăng bán (List)
    function listNFT(uint tokenId, uint price) public {
        require(nftContract.ownerOf(tokenId) == msg.sender, "You are not the owner");
        require(price > 0, "Price must be > 0");

        // Phải approve (ủy quyền) cho Marketplace trước khi gọi hàm này
        // (Sẽ hướng dẫn ở bước thao tác)
        
        // Chuyển NFT từ ví người bán vào ví của Contract Marketplace
        nftContract.transferFrom(msg.sender, address(this), tokenId);

        listings[tokenId] = Listing({
            seller: msg.sender,
            price: price,
            active: true
        });
    }

    // HÀM 2: Mua hàng (Buy) - Tính cả Royalty
    function buyNFT(uint tokenId) public payable {
        Listing storage listing = listings[tokenId];
        require(listing.active, "Item is not for sale");
        require(msg.value >= listing.price, "Not enough ETH sent");

        address seller = listing.seller;
        address creator = nftContract.creators(tokenId);
        uint price = listing.price;

        // Tính toán Royalty (5% cho Creator)
        uint royalty = (price * 5) / 100;
        uint amountToSeller = price - royalty;

        // 1. Chuyển Royalty cho Creator
        payable(creator).transfer(royalty);

        // 2. Chuyển phần còn lại cho Seller
        payable(seller).transfer(amountToSeller);

        // 3. Chuyển NFT từ Contract Marketplace cho Buyer
        nftContract.transferFrom(address(this), msg.sender, tokenId);

        // 4. Tắt trạng thái bán (hoặc xóa listing)
        listings[tokenId].active = false;

        emit ItemBought(tokenId, seller, msg.sender, price);
    }
}
```

## PHẦN 5: KỊCH BẢN TƯƠNG TÁC (MINT -> LIST -> BUY)

Chúng ta sẽ mô phỏng:
*   **Account 0**: Nghệ sĩ (Artist/Creator).
*   **Account 1**: Người mua đầu tiên (Buyer 1).
*   **Account 2**: Người mua thứ 2 (Buyer 2 - Mua lại từ Buyer 1).

### Kịch bản 1: Artist tạo và bán NFT (First Sale)

**Bước 9: Artist (Account 0) Mint NFT**
1.  Đảm bảo đang chọn **Account 0**.
2.  Mở rộng contract **SimpleNFT** ở mục Deployed Contracts.
3.  Mở hàm `mint`.
    *   `to`: Chọn **Account 0**.
    *   `tokenURI`: Nhập `ipfs://QmSunset...` (hoặc bất kỳ chuỗi ký tự nào đại diện cho ảnh).
4.  Click **mint**.
5.  Kết quả: Token ID là **1**.

**Bước 10: Artist ủy quyền (Approve) cho Marketplace**
*Trước khi bán, bạn phải cho phép Contract Marketplace được quyền di chuyển NFT của bạn.*
1.  Vẫn trong contract **SimpleNFT**, tìm hàm `setApprovalForAll`.
2.  `operator`: Dán địa chỉ của Contract **NFTMarketplace**.
3.  `approved`: Chọn `true`.
4.  Click **setApprovalForAll**.

**Bước 11: Artist đăng bán (List)**
1.  Mở rộng contract **NFTMarketplace**.
2.  Mở hàm `listNFT`.
    *   `tokenId`: Nhập `1`.
    *   `price`: Nhập `2000000000000000000` (Đây là 2 ETH, vì 1 ETH = 10^18 Wei).
3.  Click **listNFT**.
    *   *Logic:* NFT ID 1 đã chuyển từ Account 0 vào ví của Contract Marketplace.

### Kịch bản 2: Buyer 1 mua NFT

**Bước 12: Buyer 1 (Account 1) Mua (Buy)**
1.  Chuyển sang **Account 1**.
2.  Mở contract **NFTMarketplace**.
3.  Mở hàm `buyNFT`.
    *   `tokenId`: Nhập `1`.
    *   `value`: Nhập `2000000000000000000` (2 ETH).
4.  Click **buyNFT**.
5.  **Kiểm tra:**
    *   Account 1 giờ sở hữu NFT ID 1 (Check hàm `ownerOf` trong SimpleNFT).
    *   Account 0 (Artist) nhận được 2 ETH (Lần đầu bán = 100% tiền bán, không trừ royalty vì bán chính mình, hoặc code tính royalty trả lại cho chính mình cũng được).

### Kịch bản 3: Resale & Verify Royalty (QUAN TRỌNG)

Đây là bước chứng minh tính năng **Royalty**: Khi bán lại, Creator (Account 0) vẫn nhận được 5%.

**Bước 13: Buyer 1 (Account 1) Bán lại (Resale) với giá cao hơn**
1.  Đảm bảo đang chọn **Account 1**.
2.  Vào **SimpleNFT** contract -> `setApprovalForAll` -> Cho phép **NFTMarketplace** (như Bước 10).
3.  Vào **NFTMarketplace** contract -> `listNFT`.
    *   `tokenId`: `1`.
    *   `price`: `5000000000000000000` (5 ETH - Giá cao hơn để thấy lợi nhuận).
4.  Click **listNFT**.

**Bước 14: Buyer 2 (Account 2) Mua lại**
1.  Chuyển sang **Account 2**.
2.  Vào **NFTMarketplace** contract -> `buyNFT`.
    *   `tokenId`: `1`.
    *   `value`: `5000000000000000000` (5 ETH).
3.  Click **buyNFT**.

**Bước 15: Kiểm tra Royalty (Kết quả phân bổ tiền)**
Sau khi mua thành công, hãy kiểm tra số dư (Balance) của các tài khoản:

1.  **Account 2 (Buyer 2):** Trừ 5 ETH.
2.  **Account 1 (Seller):** Nhận được **4.75 ETH** (95% của 5 ETH).
3.  **Account 0 (Creator):** Nhận được **0.25 ETH** (5% Royalty của 5 ETH).

*Để xem số dư rõ ràng trong Remix:*
*   Nhìn lên mục **Account**, bạn sẽ thấy số dư ETH giảm/tăng của từng tài khoản sau mỗi giao dịch (phía sau địa chỉ ví).

=> **Kết luận:** Logic Royalty hoạt động chính xác. Ngay cả khi Account 0 không bán hàng, họ vẫn nhận được tiền bản quyền từ việc mua bán lại.
