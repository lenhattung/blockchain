# HƯỚNG DẪN THỰC HÀNH: VOTING SYSTEM TRÊN REMIX

## PHẦN 1: THIẾT LẬP VÀ VIẾT CODE

### Bước 1: Truy cập Remix
1.  Mở trình duyệt web (Chrome, Edge, Firefox...).
2.  Truy cập địa chỉ: [https://remix.ethereum.org/](https://remix.ethereum.org/)

### Bước 2: Tạo file hợp đồng mới
1.  Nhìn vào cột bên trái, click vào biểu tượng **File Explorers** (biểu tượng thư mục).
2.  Click vào nút **Create New File** (biểu tượng trang giấy trắng có dấu cộng) trong cột bên trái.
3.  Đặt tên file là: `VotingSystem.sol`
    *   *Lưu ý: Đảm bảo đuôi file là `.sol` (Solidity).*

### Bước 3: Viết mã nguồn (Smart Contract)
Copy toàn bộ mã nguồn dưới đây và dán vào file `VotingSystem.sol` vừa tạo.

Mã này bao gồm:
*   Struct `Voter` và `Proposal` như bài giảng.
*   Constructor để khởi tạo 3 ứng viên (Alice, Bob, Charlie).
*   Hàm `giveRightToVote` để Chairman cấp quyền và gán trọng số (weight).
*   Hàm `vote` để thực hiện bỏ phiếu.

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

contract VotingSystem {
    
    // --- Cấu trúc dữ liệu (Structs) ---
    struct Voter {
        uint weight;     // Trọng số vote
        bool voted;      // Đã vote chưa
        uint vote;       // Index của proposal đã vote
    }

    struct Proposal {
        string name;     // Tên ứng viên
        uint voteCount;  // Tổng vote nhận được
    }

    // --- Biến trạng thái (State Variables) ---
    address public chairperson; // Người quản trị (Chairman)
    mapping(address => Voter) public voters; // Danh sách cử tri
    Proposal[] public proposals; // Danh sách ứng viên

    // --- Constructor (Khởi tạo) ---
    // Nhận vào mảng tên ứng viên để tạo danh sách bầu cử
    constructor(string[] memory proposalNames) {
        chairperson = msg.sender;
        voters[chairperson].weight = 1; // Chairman mặc định có quyền (nếu cần)

        // Tạo danh sách ứng viên từ mảng tên đầu vào
        for (uint i = 0; i < proposalNames.length; i++) {
            proposals.push(Proposal({
                name: proposalNames[i],
                voteCount: 0
            }));
        }
    }

    // --- Functions ---

    // Hàm Chairman cấp quyền vote cho người khác kèm theo trọng số (Weight)
    function giveRightToVote(address voter, uint weight) public {
        require(msg.sender == chairperson, "Only chairperson can give right to vote.");
        require(!voters[voter].voted, "The voter already voted.");
        require(voters[voter].weight == 0, "Voter already has voting rights.");

        voters[voter].weight = weight;
    }

    // Hàm Bỏ phiếu (Vote)
    function vote(uint proposalIndex) public {
        Voter storage sender = voters[msg.sender];

        // 1. Check quyền vote (Weight > 0)
        require(sender.weight > 0, "No right to vote");
        
        // 2. Check đã vote chưa
        require(!sender.voted, "Already voted");

        // 3. Đánh dấu đã vote
        sender.voted = true;
        sender.vote = proposalIndex;

        // 4. Cộng trọng số (Weight) vào ứng viên
        proposals[proposalIndex].voteCount += sender.weight;
    }

    // Hàm xem kết quả (Helper để dễ đọc)
    function getResults() public view returns (string[] memory, uint[] memory) {
        string[] memory names = new string[](proposals.length);
        uint[] memory counts = new uint[](proposals.length);

        for (uint i = 0; i < proposals.length; i++) {
            names[i] = proposals[i].name;
            counts[i] = proposals[i].voteCount;
        }
        return (names, counts);
    }
}
```

## PHẦN 2: BIÊN DỊCH (COMPILE) VÀ TRIỂN KHAI (DEPLOY)

### Bước 4: Biên dịch hợp đồng
1.  Click vào biểu tượng **Solidity Compiler** (biểu tượng chữ "S") ở cột bên trái.
2.  Trong phần "Compiler", chọn phiên bản: **0.8.20** (hoặc mới hơn).
3.  Click nút blue **Compile VotingSystem.sol**.
4.  Nếu thành công, bạn sẽ thấy dấu tích xanh bên cạnh nút compile.

### Bước 5: Triển khai (Deploy) lên môi trường ảo
1.  Click vào biểu tượng **Deploy & Run Transactions** (biểu tượng Ether mũi tên xuống) ở cột bên trái.
2.  Tại mục **Environment**, chọn **Remix VM (Cancun)**. (Đây là Blockchain ảo trên trình duyệt để test).
3.  Mục **CONTRACT** chọn: `VotingSystem`.
4.  Nhìn xuống phần nút **Deploy**, có một ô input `proposalNames`. Đây là nơi nhập danh sách ứng viên.
    *   Nhập chính xác: `["Alice", "Bob", "Charlie"]`
    *   *(Lưu ý: Dấu ngoặc vuông, dấu ngoặc kép và dấu phẩy rất quan trọng).*
5.  Click nút **Deploy** (màu cam).

## PHẦN 3: THỰC HIỆN KỊCH BẢN BẦU CỬ (TESTING)

Sau khi Deploy, ở phần dưới cùng bên trái, mục **Deployed Contracts**, click vào mũi tên tên `> VotingSystem` để mở rộng danh sách hàm.

### Bước 6: Cấp quyền cho cử tri (Setup Weights)
Theo yêu cầu bài tập: Chairman cần cấp quyền cho 5 addresses với weights khác nhau:
*   Sinh viên B: weight = 1
*   Sinh viên C: weight = 2
*   Sinh viên D, E, F: weight = 1

Chúng ta sẽ dùng 5 tài khoản có sẵn của Remix VM (Account 1 đến Account 5).
*Lưu ý: Account 0 là Chairman.*

1.  **Cấp quyền cho Sinh viên B (Account 1, Weight 1):**
    *   Mở hàm `giveRightToVote`.
    *   `voter`: Click vào icon tài khoản -> Chọn **Account 1** (0x5B3...).
    *   `weight`: Nhập `1`.
    *   Click nút **giveRightToVote** (màu cam).
    *   *Kết quả:* Xuất hiện một tick màu xanh ở terminal bên phải.

2.  **Cấp quyền cho Sinh viên C (Account 2, Weight 2):**
    *   `voter`: Chọn **Account 2**.
    *   `weight`: Nhập `2`.
    *   Click **giveRightToVote**.

3.  **Cấp quyền cho Sinh viên D, E, F (Account 3, 4, 5, Weight 1):**
    *   Làm tương tự cho Account 3, 4, 5 với `weight` là `1`.

### Bước 7: Thực hiện bỏ phiếu (Voting)
Chúng ta sẽ đổi tài khoản để giả lập mỗi người bỏ phiếu.

**Cách đổi tài khoản:**
Ở phần **Deploy & Run Transactions**, nhìn mục **Account**, click vào dropdown và chọn Account tương ứng (1, 2, 3, 4, 5).

1.  **Sinh viên B (Account 1) bầu cho Alice:**
    *   Chọn **Account 1** ở mục Account.
    *   Mở hàm `vote`.
    *   `proposalIndex`: Nhập `0` (Alice là vị trí số 0).
    *   Click **vote**.

2.  **Sinh viên C (Account 2, Weight 2) bầu cho Bob:**
    *   Đổi sang **Account 2**.
    *   Mở hàm `vote`.
    *   `proposalIndex`: Nhập `1` (Bob là vị trí số 1).
    *   Click **vote**. (Điểm Bob sẽ tăng lên 2 vì Sinh viên C có weight = 2).

3.  **Sinh viên D (Account 3) bầu cho Bob:**
    *   Đổi sang **Account 3**.
    *   `vote` với `proposalIndex`: `1`.
    *   Click **vote**. (Điểm Bob giờ là 2 + 1 = 3).

4.  **Sinh viên E (Account 4) bầu cho Charlie:**
    *   Đổi sang **Account 4**.
    *   `vote` với `proposalIndex`: `2` (Charlie).
    *   Click **vote**.

5.  **Sinh viên F (Account 5) bầu cho Alice:**
    *   Đổi sang **Account 5**.
    *   `vote` với `proposalIndex`: `0`.
    *   Click **vote**. (Điểm Alice giờ là 1 + 1 = 2).

### Bước 8: Kiểm tra kết quả (Real-Time)
Có 2 cách để xem kết quả:

**Cách 1: Xem trực tiếp biến `proposals`**
1.  Trong mục **Deployed Contracts**, tìm biến `proposals` (màu xanh).
2.  Nhập `0` và click nút рядом (đọc dữ liệu).
    *   `name`: "Alice", `voteCount`: 2.
3.  Nhập `1` và click.
    *   `name`: "Bob", `voteCount`: 3.
4.  Nhập `2` và click.
    *   `name`: "Charlie", `voteCount`: 1.

**Kết quả khớp với Slide:** Bob thắng với 3 votes.

**Cách 2: Dùng hàm `getResults`**
1.  Mở hàm `getResults`.
2.  Click nút **getResults**.
3.  Kết quả trả về:
    *   `0 (string[] memory)`: `["Alice", "Bob", "Charlie"]`
    *   `1 (uint[] memory)`: `["2", "3", "1"]`

### Bước 9: Kiểm tra chống gian lận (Vote 2 lần)
1.  Hãy cố gắng vote lại bằng **Account 1** (đã vote cho Alice).
2.  Đảm bảo đang chọn Account 1.
3.  Thực hiện `vote` với index bất kỳ.
4.  **Kết quả:** Giao dịch sẽ thất bại (báo đỏ).
    *   Thông báo lỗi: `Error: Returned error: VM Exception while processing transaction: revert Already voted -- Reason given: Already voted.`
    *   Điều này chứng tỏ hệ thống đã chặn thành công việc vote 2 lần.

## PHẦN 4: THỬ THÁCH (CHALLENGE) - THÊM DEADLINE

Để hoàn thành thử thách "Thêm DEADLINE cho voting", bạn cần sửa code một chút.

### Bước 10: Sửa Code để thêm Deadline
1.  Quay lại tab file `VotingSystem.sol`.
2.  Sửa lại code như sau (tôi đã đánh dấu phần thay đổi bằng comment `// --- NEW ---`):

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

contract VotingSystem {
    
    struct Voter {
        uint weight;
        bool voted;
        uint vote;
    }

    struct Proposal {
        string name;
        uint voteCount;
    }

    address public chairperson;
    mapping(address => Voter) public voters;
    Proposal[] public proposals;

    // --- NEW: Thêm biến deadline ---
    uint public votingDeadline; 

    // Sửa Constructor để nhận thêm thời gian Deadline
    constructor(string[] memory proposalNames, uint _durationInSeconds) {
        chairperson = msg.sender;
        voters[chairperson].weight = 1;

        // --- NEW: Set deadline là thời gian hiện tại + khoảng thời gian input ---
        votingDeadline = block.timestamp + _durationInSeconds;

        for (uint i = 0; i < proposalNames.length; i++) {
            proposals.push(Proposal({
                name: proposalNames[i],
                voteCount: 0
            }));
        }
    }

    function giveRightToVote(address voter, uint weight) public {
        require(msg.sender == chairperson, "Only chairperson can give right to vote.");
        require(!voters[voter].voted, "The voter already voted.");
        require(voters[voter].weight == 0, "Voter already has voting rights.");
        voters[voter].weight = weight;
    }

    function vote(uint proposalIndex) public {
        Voter storage sender = voters[msg.sender];

        require(sender.weight > 0, "No right to vote");
        require(!sender.voted, "Already voted");
        
        // --- NEW: Check xem đã hết hạn chưa ---
        require(block.timestamp <= votingDeadline, "Voting is closed (Deadline passed)");

        sender.voted = true;
        sender.vote = proposalIndex;
        proposals[proposalIndex].voteCount += sender.weight;
    }
    
    // Hàm mới để xem còn bao lâu nữa hết hạn
    function getTimeLeft() public view returns (uint) {
        if (block.timestamp >= votingDeadline) {
            return 0;
        }
        return votingDeadline - block.timestamp;
    }
}
```

### Bước 11: Deploy lại và Test Deadline
1.  Vào **Solidity Compiler**, click **Compile VotingSystem.sol** lại.
2.  Vào **Deploy & Run Transactions**.
3.  Trong phần Deploy, giờ có thêm ô `_durationInSeconds`.
    *   Nhập `["Alice", "Bob", "Charlie"]` vào ô `proposalNames`.
    *   Nhập `60` vào ô `_durationInSeconds` (tức là chỉ được vote trong 60 giây).
4.  Click **Deploy**.
5.  Làm lại các bước cấp quyền và vote (Bước 6, 7).
6.  **Test Deadline:**
    *   Hãy đợi hơn 60 giây, hoặc trong Remix VM, bạn có thể click vào nút bent mũi tên ở góc phải mốc thời gian (bên cạnh "15s") để dịch chuyển thời gian nhanh hơn (ví dụ +1 phút).
    *   Sau khi thời gian vượt quá 60s kể từ lúc deploy, thử gọi hàm `vote` bằng bất kỳ tài khoản nào.
    *   **Kết quả:** Sẽ báo lỗi `Voting is closed (Deadline passed)`.
